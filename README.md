# ІТ-квести

Навчальні ігри для уроків. Учень входить один раз (логін і PIN з таблиці вчительки) і бачить ігри свого класу.

## Що де лежить

- `index.html`, `portal.js` — головна сторінка: вхід, список ігор, змійка й гардероб.
- `core/` — спільний рушій для всіх ігор: вхід, збереження в таблицю, змійка, скіни, штрафи за вихід з гри.
- `spysky/` — «Списковий квест» (Python, списки): `content.js` — рівні й завдання, `game.js` — логіка гри.
- `tablytsia/Code.gs` — копія скрипта для Google Таблиці (Розширення → Apps Script).

## Таблиця

- «Учні»: Логін | PIN | Ім'я | Клас.
- «Доступ»: Клас | Ігри (через кому, наприклад `spysky`). Якщо класу немає в списку, він бачить усі ігри.
- «Профілі» і «Прогрес: …» гра заповнює сама.
